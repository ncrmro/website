# Working in this repository

Read `docs/architecture.md` and `CONTRIBUTING.md`. Run every bun command in the
devenv shell from `code/web`. Do not hand-edit `bun.lock` or install Playwright
browsers outside the provided shell.

All posts use Quiescent. Preserve document identities, public URLs, publication
dates, private draft branches and original Git LFS media. Do not introduce a
second post backend or execute imported Markdown as JavaScript. The jobs
collection is independently maintained for the résumé.
